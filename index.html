Early verison of this application, currently usable for setting updating posts to have "who can quote" set to "anyone". Update will be done in batches of 20 posts at the time. The app will be expanded to make it possible to modify other parts of the your post history, and have more fine grained options for selecting what posts to process.

This functionality will be integrated into the Trunkfriends application, as part of the rewrite to Gleam/Javascript (the desktop app is no longer maintained, and the Gleam app is in early development stage)

This is a client-side-only application, the token used to process the posts, is only stored in the browser during this sessions. The only communication is between your browser, and the mastodon instance you use.

It is, regardless, a good idea to delete the token that was created during the session. This is done in the preferences section on your mastodon instance, under Account -> Authorized Apps. The tokens used by this app will have the name "quoteupdate".

The source is freely availabe, and can be built and run locally using docker.

https://github.com/steinareliassen/quoteme - Docker file can be used to both build the project and create runnable image
